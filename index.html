      How it works

      Design a label here, then print it straight from the browser over Bluetooth.

      Print your first label

      1. Use Chrome or Edge on a computer with Bluetooth.
      2. Turn on the D110_M and close the NIIMBOT phone app so it isn't holding the connection.
      3. Click Connect and pick the printer in the browser's Bluetooth window.
      4. Pick a template or add text, lines, boxes and symbols. Drag them around the label.
      5. Print one copy and check it. If it's upside down, set Print direction to Flipped.
